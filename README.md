# AsylumVR

**[▶ PLAY](https://rockstarb0i.github.io/AsylumVR/)** — open this link in the Meta Quest browser and press *Enter VR*, or play on desktop.

Mount Harrow State Asylum, recovered footage, tape 1 of 4. You are a journalist with a camcorder.
You cannot fight. Run, hide in lockers and under beds, and use night vision to see in the dark — it eats batteries.

Everything (the building, the light, the people, the sound and the music) is generated in code with three.js and Web Audio.
